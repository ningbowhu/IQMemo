# 密钥隔离与可选服务

## 默认公开版

源码中的 XfyunConfig 只引用构建生成的 BuildConfig 字段，没有真实凭据。没有设置服务参数时，Gradle 使用 your_app_id、your_api_key、your_api_secret 占位值，文字功能仍可构建、安装和使用。语音入口会说明未配置并退出，不申请录音权限或连接讯飞。

## 二次开发者配置自己的语音

1. 从 local.properties.example 复制 local.properties，设置本机 SDK 路径。
2. 如需语音，在该文件设置 XFYUN_APP_ID、XFYUN_API_KEY、XFYUN_API_SECRET，或设置同名环境变量；环境变量优先。
3. 使用自己的讯飞 IAT 账号，核实服务开通情况、计费和服务商条款，再自行构建。

不要把真实值写进源码、示例、提交说明、Issue、日志或截图。local.properties 和构建输出都在 gitignore 中。Gitignore 无法撤销历史泄露；误公开后应先撤销/轮换凭据，再清理历史。

## APK 的边界

编入客户端 APK 的服务参数可以被反编译或运行时提取。忽略本地配置、代码混淆或加密字符串不能把嵌入的密钥变成安全的服务器秘密。自行配置的版本应按自用范围保管，不公开分发含私人凭据的 APK。

GitHub Releases 的默认公开包必须在未设置上述参数的环境下构建，并检查源码、生成字段和 APK 解包内容。若未来提供公共语音服务，应另行实现后端保管密钥、用户鉴权、限额和滥用防护，而不是把共享密钥编进 APK。

## 已移除工作台；签名保持本地

公开版不包含工作台绑定、配对、设备身份、同步模块或默认地址，不需要工作台账号或令牌。它不会向工作台发送备忘录内容。

正式签名私钥和密码只保存在维护者本地，通过 local.properties 或环境变量注入，不上传仓库或 Releases。APK 签名证书属于公开验证信息，私钥不属于公开材料。第三方修改后可用自己的签名安装；不同签名不能覆盖升级已有应用。
